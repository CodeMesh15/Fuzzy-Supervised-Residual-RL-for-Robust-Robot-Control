# Presentation Deck

This folder contains a presentation-ready slide deck for the fuzzy-supervised residual RL study.

- `fuzzy_td3_presentation.pdf`: compiled 19-slide deck.
- `fuzzy_td3_presentation.tex`: editable Beamer source.
- `speaker_notes.md`: slide-by-slide speaking notes for a 10 to 12 minute presentation.

To rebuild the PDF from this folder:

```powershell
pdflatex -interaction=nonstopmode fuzzy_td3_presentation.tex
```
